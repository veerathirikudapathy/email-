# MailGuard — Email Spam Classification

A runnable machine-learning web application built with Python, Flask, scikit-learn, HTML, CSS, and JavaScript.

## Features
- Paste an email message into a clean web interface.
- Classify it as **Spam** or **Not Spam**.
- Display the model's estimated confidence and both class scores.
- Train the model again from the included CSV dataset.
- JSON prediction API at `POST /api/predict`.

## Requirements
- Python 3.10 or newer
- pip

## Setup (Windows)

Open Command Prompt or the VS Code terminal in this project folder:

```bash
py -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

On macOS/Linux, activate the environment with:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Train the model

```bash
python train_model.py
```

The training script:
1. Loads `data/emails.csv`.
2. Splits the data into training and test sets using stratification.
3. Converts text to TF-IDF features (unigrams and bigrams).
4. Trains a Multinomial Naive Bayes classifier.
5. Prints accuracy, precision, recall, F1-score, and a confusion matrix.
6. Saves the fitted pipeline to `model/spam_classifier.joblib`.

## Run the web app

```bash
python app.py
```

Open **http://127.0.0.1:5000** in your browser.

Stop the server with `Ctrl+C`.

## API example

Request:

```bash
curl -X POST http://127.0.0.1:5000/api/predict ^
  -H "Content-Type: application/json" ^
  -d "{\"message\":\"Congratulations! You won a free prize. Claim now.\"}"
```

Example response shape:

```json
{
  "label": "spam",
  "display_label": "Spam",
  "confidence": 80.12,
  "probabilities": {
    "ham": 19.88,
    "spam": 80.12
  }
}
```

Actual confidence values depend on the trained model and dataset.

## Dataset and model limitations

`data/emails.csv` is a small, hand-curated **demonstration dataset** created for this project. It is useful for checking that the complete application runs, but it is not large or representative enough for real-world email filtering. The test-set score from this small dataset is only a software/demo check and should not be presented as production accuracy.

For a stronger project:
- Replace or expand the CSV with a properly licensed, real-world labeled email/SMS spam dataset.
- Keep labels exactly `spam` and `ham`, with columns named `text` and `label`.
- Remove duplicates and check class balance.
- Evaluate on a separate, representative test set.
- Consider false-positive cost carefully: legitimate messages incorrectly marked as spam can be harmful.
- Do not use the demo model as the only security filter. Never paste passwords, private keys, or sensitive personal data into the demo.

## Retraining after changing the CSV

Keep the same CSV column names (`text`, `label`) and labels (`spam`, `ham`), then run:

```bash
python train_model.py
```

Restart the Flask app after retraining so it loads the newly saved model.

## Troubleshooting
- **Model not found:** run `python train_model.py` before `python app.py`.
- **Module not found:** activate your virtual environment and run `pip install -r requirements.txt`.
- **Port 5000 is busy:** change `port=5000` in the final `app.run(...)` line of `app.py` to another port, such as `5001`.
